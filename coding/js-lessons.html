JavaScript Lessons — Beginner Track

JavaScript is the language that makes web pages interactive. These 8 short, original lessons take you from zero to simple page interaction. Every lesson has a small example — press Try in Editor and the example opens ready inside the StudySphere Coding Lab, where you can run it and change it.

Beginner Roadmap: 1. HTML → 2. CSS → 3. JavaScript (these lessons + Coding Lab practice) → 4. C++ (lessons on the site) → 5. Python (lessons on the site) → 6. Data Science & AI. Python and C++ are taught through lessons and code reading; they do not run inside the browser editor — only HTML, CSS and JavaScript run there.

Lesson 1 — Variables & Data Types

A variable is a named box that stores a value. Use let for values that can change and const for values that stay fixed. Common data types are strings (text in quotes), numbers, and booleans (true/false).

let name = "Ali";
const age = 20;
let isStudent = true;
document.getElementById("out").textContent = name + " is " + age + " years old.";
Exercise: Change the name and age to your own, and add a third line that also prints "Student: yes" or "Student: no" using the boolean.

Lesson 2 — Operators

Operators do work on values: + − * / % for maths (% gives the remainder), === compares values, and && / || combine true/false conditions.

let a = 17, b = 5;
let sum = a + b;        // 22
let rest = a % b;       // 2
document.getElementById("out").textContent = "Sum = " + sum + ", Remainder = " + rest;
Exercise: Store a price and a quantity, then print the total bill using multiplication.

Lesson 3 — Conditions (if / else)

Programs make decisions with if: if a condition is true, one block runs; otherwise the else block runs.

let marks = 72;
let msg;
if (marks >= 50) { msg = "Pass"; } else { msg = "Fail"; }
document.getElementById("out").textContent = msg;
Exercise: Add an "else if" branch so marks of 80 or more print "Distinction".

Lesson 4 — Loops

A for loop repeats a block a set number of times — perfect for tables, lists and counting.

let text = "";
for (let i = 1; i <= 5; i++) { text += i + " "; }
document.getElementById("out").textContent = text;
Exercise: Change the loop to print the multiplication table of 7 (7, 14, 21 … 70).

Lesson 5 — Functions

A function is a reusable block of code. You define it once, then call it whenever you need it — it can take inputs (parameters) and give back a result with return.

function square(n) { return n * n; }
document.getElementById("out").textContent = "Square of 6 is " + square(6);
Exercise: Write a function addTax(price) that returns the price plus 10%.

Lesson 6 — Arrays

An array stores a list of values in one variable. Items are counted from index 0, and .length tells you how many items there are.

let fruits = ["Apple", "Banana", "Mango"];
document.getElementById("out").textContent = fruits[0] + " — total: " + fruits.length;
Exercise: Use a loop to print all the fruits, one per line.

Lesson 7 — Strings & Methods

Strings have built-in tools called methods: .length counts characters, .toUpperCase() makes text capital, and .includes() checks whether text contains something.

let word = "studysphere";
document.getElementById("out").textContent = word.toUpperCase() + " has " + word.length + " letters.";
Exercise: Check whether the sentence "I love coding" includes the word "coding" and print the result.

Lesson 8 — DOM Basics

The DOM is the page itself, seen as objects. JavaScript can read and change any element: find it with getElementById, then change its text or style — and react when a button is clicked.

document.getElementById("out").style.color = "#0b3d91";
document.getElementById("out").textContent = "The DOM changed this text!";
Exercise: Change the colour to a different one and make the text bold as well (hint: style.fontWeight = "bold").
