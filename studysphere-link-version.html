Coding academy

Four starter lessons in simple English. Open a lesson, read it carefully, and type the example yourself — that is how programming is actually learned.

Lesson 1 — HTML: your first web pageHTML

HTML is the skeleton of every web page. Tags tell the browser what each part of the page is.

<!DOCTYPE html>
<html>
  <head><title>My first page</title></head>
  <body>
    <h1>Assalam-o-Alaikum</h1>
    <p>This is my first web page.</p>
  </body>
</html>

<h1> is a big heading, <p> is a paragraph. Almost every tag opens and closes — what goes between them is the content.

Lesson 2 — CSS: making pages clear and readableCSS

CSS controls how a page looks — colours, sizes, spacing and layout.

h1 { color: #166649; }
p { font-size: 18px; line-height: 1.6; }

Each rule names an element, then lists its styles inside curly brackets.

Lesson 3 — C++: variables and outputC++

C++ is the language taught in most Pakistani universities. A variable is a named box that stores a value.

#include <iostream>
using namespace std;
int main() {
    int marks = 85;
    cout << "My marks are " << marks;
    return 0;
}

int stores whole numbers, cout prints to the screen.

Lesson 4 — Python: a friendly startPython

Python reads almost like English, which makes it a good first language for data science and AI.

name = "Mutiu"
marks = [80, 75, 90, 88]
average = sum(marks) / len(marks)
print(name, "your average is", average)

No semicolons, no curly brackets — just clean, readable code.
