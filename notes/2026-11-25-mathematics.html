Matrices & Determinants — Order, Addition, Multiplication and Inverse

Mathematics Matrices & Determinants 10 Practice MCQs

A matrix is simply a neat box of numbers — and once you know the few rules for adding, multiplying and finding determinants, most test questions become easy marks. These notes explain matrices step by step in simple English with Roman Urdu help, made for SPSC, teaching and screening tests.

1. What Is a Matrix?

A matrix is a rectangular arrangement of numbers (or symbols) in rows and columns, written inside square brackets. Roman Urdu: Matrix numbers ko rows (qataron) aur columns (sutunon) mein tartib se likhne ka tareeqa hai.

A = [ 1   2   3 ;   4   5   6 ]

The matrix above has 2 rows and 3 columns. Its order is written as 2 × 3 (read as "two by three") — rows first, then columns. The numbers inside are called the elements (or entries) of the matrix. A 2 × 3 matrix has 2 × 3 = 6 elements.

Each element has a position. In the matrix A above, the element in the 1st row and 2nd column is written as a12 = 2, and a23 = 6. Test tip: the first number in the order always counts the rows, the second counts the columns — tests often swap them to trap you.

Remember: a matrix is not a number — it is a whole arrangement of numbers. But we can add, subtract and multiply matrices by fixed rules, and we can find the determinant of a square matrix.

2. Types of Matrices

Learn these types by their shapes — tests ask "which of these is a column matrix" or "which is an identity matrix" again and again.

TypeWhat it isExample
Row matrixOnly one row[ 1   2   3 ]

Square matrixRows = columns (order n × n)[ 1   2 ; 3   4 ]
Rectangular matrixRows ≠ columns[ 1   2   3 ; 4   5   6 ]
Zero (null) matrixAll elements are 0[ 0   0 ; 0   0 ]
Diagonal matrixSquare matrix; all elements off the main diagonal are 0[ 2   0 ; 0   5 ]

Identity (unit) matrixDiagonal elements are all 1 — written as I[ 1   0 ; 0   1 ]

The identity matrix I is special: multiplying any matrix by I leaves it unchanged — A × I = I × A = A. It works like the number 1 in ordinary multiplication. Roman Urdu: Identity matrix wahi kaam karti hai jo aam hisaab mein 1 karta hai — kisi bhi matrix ko I se multiply karein to wohi matrix wapas milti hai.

3. Addition, Subtraction and Scalar Multiplication

Rule 1 — same order only: two matrices can be added or subtracted only if they have the same order. Add (or subtract) the elements that sit in the same position.

[ 1   2 ; 3   4 ] + [ 5   6 ; 7   8 ] = [ 6   8 ; 10   12 ]

Check: 1 + 5 = 6, 2 + 6 = 8, 3 + 7 = 10, 4 + 8 = 12. Subtraction works the same way, with minus instead of plus.

Rule 2 — scalar multiplication: to multiply a matrix by a number (called a scalar), multiply every element by that number.

3 × [ 1   2 ; 0   5 ] = [ 3   6 ; 0   15 ]

Test trap: a 2 × 3 matrix can never be added to a 3 × 2 matrix — the orders are different, so addition is impossible. If a question asks "which of these additions is possible", just compare the orders.

4. Matrix Multiplication

Rule — the middle numbers must match: A × B is possible only if the number of columns of A equals the number of rows of B. The product then has the order: rows of A × columns of B.

(2 × 3) × (3 × 2) = (2 × 2)   |   (2 × 3) × (2 × 3) = not possible

How to multiply: each element of the product is the row × column sum — multiply the row of the first matrix by the matching column of the second matrix, then add.

[ 1   2 ; 3   4 ] × [ 5   6 ; 7   8 ] = [ 19   22 ; 43   50 ]

Check the first element: row 1 of A is (1, 2) and column 1 of B is (5, 7), so 1 × 5 + 2 × 7 = 5 + 14 = 19. The other three: 1 × 6 + 2 × 8 = 22; 3 × 5 + 4 × 7 = 43; 3 × 6 + 4 × 8 = 50.

Very important — multiplication is NOT commutative: in general, A × B ≠ B × A. In ordinary numbers 2 × 3 = 3 × 2, but for matrices the order matters — and sometimes B × A is not even possible. Roman Urdu: Aam numbers mein 2 × 3 aur 3 × 2 barabar hote hain, lekin matrices mein A × B aur B × A aksar barabar nahi hote — tartib ka khayal rakhein.

Other useful facts: A × I = A (identity changes nothing), and A × 0 = 0 (the zero matrix).

5. Transpose of a Matrix

The transpose of a matrix, written AT, is made by turning its rows into columns and its columns into rows.

If A = [ 1   2 ; 3   4 ], then AT = [ 1   3 ; 2   4 ]

The first row (1, 2) becomes the first column. A 2 × 3 matrix becomes a 3 × 2 matrix when transposed — the order flips.

Rules to remember: (AT)T = A — transposing twice brings the original matrix back. And (A × B)T = BT × AT — the order reverses, just like taking off shoes and socks in reverse order.

6. Determinant of a Matrix

A determinant is a single number worked out from a square matrix only. It is written with straight bars: | A | or det(A). Roman Urdu: Determinant aik square matrix se nikalne wala aik number hota hai — ye batata hai ke matrix ka inverse hai ya nahi.

2 × 2 determinant — the "cross" rule: multiply the main diagonal, then subtract the product of the other diagonal.

det [ a   b ; c   d ] = ad − bc

Example: det [ 2   3 ; 1   4 ] = 2 × 4 − 3 × 1 = 8 − 3 = 5.

3 × 3 determinant — expand along the first row: take each element of the first row in turn, multiply it by the determinant of the 2 × 2 matrix that is left when you cross out its row and column, with signs +, −, +.

Example: det [ 1   2   3 ; 0   1   4 ; 5   6   0 ]
= 1 × (1 × 0 − 4 × 6) − 2 × (0 × 0 − 4 × 5) + 3 × (0 × 6 − 1 × 5)
= 1 × (−24) − 2 × (−20) + 3 × (−5) = −24 + 40 − 15 = 1.

Useful facts: det(A × B) = det(A) × det(B). The determinant of the identity matrix is 1. If two rows (or two columns) of a matrix are the same, its determinant is 0.

7. Singular Matrices and the Inverse

Singular matrix: a square matrix whose determinant is 0. A singular matrix has no inverse — this is one of the most-asked facts in job tests.

Non-singular matrix: a square matrix whose determinant is not 0. Only a non-singular matrix has an inverse, written A−1, and A × A−1 = A−1 × A = I.

Inverse of a 2 × 2 matrix — the quick formula: swap the two diagonal elements, change the sign of the other two, then divide everything by the determinant.

If A = [ a   b ; c   d ], then A−1 = (1 / det A) × [ d   −b ; −c   a ]

Example: A = [ 4   7 ; 2   6 ]. First the determinant: det A = 4 × 6 − 7 × 2 = 24 − 14 = 10 (not 0, so the inverse exists). Then A−1 = (1/10) × [ 6   −7 ; −2   4 ] = [ 0.6   −0.7 ; −0.2   0.4 ].

Check it: A × A−1 = [ 1   0 ; 0   1 ] = I. If the answer is not the identity matrix, the inverse is wrong.

Test trap: if a question gives a matrix with determinant 0 and asks for its inverse, the correct answer is "the inverse does not exist" — do not try to calculate it.

Quick Facts — Test Mein Aane Wale Points

  • A matrix of order m × n has m × n elements. A 3 × 4 matrix has 12 elements.
  • Addition and subtraction need the same order; scalar multiplication multiplies every element.
  • A × B is possible only if columns of A = rows of B; the product has order (rows of A) × (columns of B).
  • Matrix multiplication is NOT commutative: A × B ≠ B × A in general.
  • A × I = A and A × 0 = 0, where I is the identity matrix and 0 is the zero matrix.
  • Transpose: rows become columns; (AT)T = A and (A × B)T = BT × AT.
  • 2 × 2 determinant: det [ a   b ; c   d ] = ad − bc. Determinants exist only for square matrices.
  • det(A × B) = det(A) × det(B); det(I) = 1; equal rows or columns make the determinant 0.
  • Singular matrix: determinant = 0, no inverse. Non-singular: determinant ≠ 0, inverse exists.
  • Inverse of a 2 × 2 matrix: (1 / det) × [ d   −b ; −c   a ] — swap the diagonal, change the signs of the other two.

  1. What is the order of a matrix with 2 rows and 3 columns?
    (a) 3 × 2   (b) 2 × 3   (c) 5   (d) 6
  2. Two matrices can be added only if they have…
    (a) The same number of rows   (b) The same order   (c) The same determinant   (d) The same first element
  3. [ 1   2 ; 3   4 ] + [ 5   6 ; 7   8 ] = ?
    (a) [ 6   8 ; 10   12 ]   (b) [ 5   12 ; 21   32 ]   (c) [ 6   6 ; 10   10 ]   (d) [ 4   4 ; 4   4 ]
  4. What is the determinant of [ 2   3 ; 1   4 ]?
    (a) 11   (b) 5   (c) 2   (d) 10
  5. The identity matrix of order 2 is…
    (a) [ 1   1 ; 1   1 ]   (b) [ 1   0 ; 0   1 ]   (c) [ 0   0 ; 0   0 ]   (d) [ 2   0 ; 0   2 ]
  6. The transpose of [ 1   2 ; 3   4 ] is…
    (a) [ 1   3 ; 2   4 ]   (b) [ 4   3 ; 2   1 ]   (c) [ 1   2 ; 3   4 ]   (d) [ 2   1 ; 4   3 ]
  7. A 2 × 3 matrix is multiplied by a 3 × 2 matrix. What is the order of the product?
    (a) 3 × 3   (b) 2 × 2   (c) 2 × 3   (d) Cannot be multiplied
  8. If the determinant of a matrix is 0, the matrix is called…
    (a) Identity   (b) Singular   (c) Symmetric   (d) Diagonal
  9. What is 2 × [ 3   1 ; 0   2 ]?
    (a) [ 6   2 ; 0   4 ]   (b) [ 5   3 ; 2   4 ]   (c) [ 3   1 ; 0   2 ]   (d) [ 6   1 ; 0   4 ]
  10. For A = [ 4   7 ; 2   6 ], what is the inverse A−1?
