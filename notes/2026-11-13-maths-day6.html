Topic 1: Number System, LCM & HCF — Short Notes

  • Natural numbers are 1, 2, 3, 4, ... Whole numbers are 0, 1, 2, 3, ... Integers are ..., -2, -1, 0, 1, 2, ... (negative, zero and positive).
  • A prime number has only two factors: 1 and itself (2, 3, 5, 7, 11, 13, ...). 2 is the only even prime number and also the smallest prime number. A composite number has more than two factors (4, 6, 8, 9, 10, 12, ...). 1 is neither prime nor composite.
  • Divisibility rules: a number is divisible by 2 if it ends in 0, 2, 4, 6 or 8; by 3 if the sum of its digits is divisible by 3; by 5 if it ends in 0 or 5; by 9 if the sum of its digits is divisible by 9; by 10 if it ends in 0.
  • HCF (Highest Common Factor) is the largest number that divides two or more numbers exactly. LCM (Lowest Common Multiple) is the smallest number that is a multiple of two or more numbers.
  • Important formula: Product of two numbers = HCF × LCM. Example: for 12 and 18, HCF = 6 and LCM = 36, and 12 × 18 = 216 = 6 × 36.
  • Sum of first n natural numbers = n × (n + 1) / 2. Example: 1 + 2 + ... + 10 = 10 × 11 / 2 = 55. Sum of first n odd numbers = n2. Example: 1 + 3 + 5 + 7 + 9 = 25 = 52.

Topic 2: Sets & Basic Statistics — Short Notes

  • A set is a collection of well-defined objects. Each object in a set is called an element or member. We write sets in curly brackets: {a, e, i, o, u} is the set of vowels.
  • The symbol ∈ means “is an element of” and ∉ means “is not an element of”. The symbol ⊆ means “is a subset of”. A subset is a set made only from the elements of another set: {1, 2} is a subset of {1, 2, 3}.
  • The empty set (or null set) has no elements and is written as ∅ or { }. A set with n elements has 2n subsets. Example: {a, b, c} has 23 = 8 subsets.
  • Union (A ∪ B) means all elements of A and B together. Intersection (A ∩ B) means only the elements common to both. Formula: n(A ∪ B) = n(A) + n(B) − n(A ∩ B).
  • Mean (average) = sum of all values ÷ number of values. Median = the middle value when data is arranged in order (for an even count, take the average of the two middle values). Mode = the value that appears most often.
  • Range = largest value − smallest value. Data means collected facts or numbers; the number of times a value appears is its frequency.
