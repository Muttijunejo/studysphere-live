Computer Basics Book — Notes & MCQs

Computer Basics · SPSC / FPSC / Teaching & Screening Tests · By MR Academy

Almost every government test now includes basic computer questions — for computer operator, data entry, teaching and general screening posts. This book covers hardware, software, MS Office, the internet, shortcut keys and storage units in simple words, with 15 practice MCQs at the end.

Computer Parts and Hardware

A computer is an electronic machine that takes data (input), processes it, and gives information (output). Its physical parts are called hardware.

  • CPU (Central Processing Unit) — the "brain" of the computer; it does all calculations and controls all parts.
  • Input devices — keyboard, mouse, scanner, microphone: they send data into the computer.
  • Output devices — monitor, printer, speakers: they show or give out the result.
  • Monitor is also called the VDU (Visual Display Unit).
  • Printer types: inkjet and laser are common today; a printer's output on paper is called a hard copy, while output on screen is a soft copy.

Software Types

Software is the set of instructions (programs) that tells the hardware what to do. You cannot touch software.

  • System software — runs the computer itself. The most important is the Operating System (examples: Windows, Linux, Android). It starts the computer and manages all other programs.
  • Application software — programs for the user's work: MS Word, MS Excel, web browsers, media players, games.
  • The process of starting a computer is called booting.
  • A virus is a harmful program; antivirus software removes it.

MS Word, Excel and PowerPoint Basics

  • MS Word — used for writing documents like letters and applications. Word files are saved with the extension .docx. The default font size and margins can be changed from the Home and Layout tabs.
  • MS Excel — used for calculations and records in a spreadsheet made of rows and columns. The box where a row and column meet is a cell. Every formula in Excel starts with the = sign, for example =SUM(A1:A5) adds five cells.
  • MS PowerPoint — used for making presentations. Each page of a presentation is called a slide. Press F5 to start the slideshow.
  • A file is a saved piece of work; files are organised inside folders.

Internet and Email

  • The Internet is a worldwide network of computers. The World Wide Web (WWW) is the system of websites on the internet, invented by Tim Berners-Lee.
  • A web browser (Chrome, Firefox, Edge) opens websites. A search engine (like Google) finds information.
  • Every website has an address called a URL. Websites open with http:// or the secure https://.
  • Email is electronic mail. An email address has two parts joined by @, for example name@example.com. CC sends a copy to others openly; BCC sends a hidden copy; unwanted junk mail is called spam.
  • Files sent with an email are called attachments.

Data and Storage Units

  • The smallest unit of data is a bit (0 or 1). 8 bits = 1 byte.
  • In test books: 1 KB = 1,024 bytes · 1 MB = 1,024 KB · 1 GB = 1,024 MB · 1 TB = 1,024 GB.
  • Order from small to large: Bit → Byte → KB → MB → GB → TB.
  • RAM is temporary (volatile) memory — data is lost when the computer is switched off. It is the computer's working memory.
  • ROM is permanent (non-volatile) memory that holds start-up instructions.
  • Storage devices: hard disk (HDD), solid state drive (SSD — faster), USB flash drive, memory card, CD/DVD.
  • Memory and storage sizes are measured in MB, GB and TB.

    (a) Monitor (b) CPU (c) Keyboard (d) Printer

    (a) Monitor (b) Printer (c) Scanner (d) Speaker
  3. Windows is an example of:
    (a) Application software (b) An operating system (c) A virus (d) A web browser
  4. In MS Excel, every formula begins with:
    (a) + (b) # (c) = (d) @
  5. A page of a PowerPoint presentation is called a:
    (a) Sheet (b) Slide (c) Page (d) Document
  6. The World Wide Web was invented by:
    (a) Bill Gates (b) Charles Babbage (c) Tim Berners-Lee (d) Steve Jobs
  7. Junk or unwanted email is called:
    (a) Inbox (b) Spam (c) Draft (d) Attachment
  8. The shortcut key for "Paste" is:
    (a) Ctrl + C (b) Ctrl + X (c) Ctrl + V (d) Ctrl + P
  9. How many bits are there in one byte?
    (a) 4 (b) 8 (c) 16 (d) 1,024
  10. Which memory loses its data when the computer is switched off?
    (a) ROM (b) Hard disk (c) RAM (d) CD
  11. The printed output of a computer is called a:
    (a) Soft copy (b) Hard copy (c) Backup (d) File
  12. The smallest unit of data is a:
    (a) Byte (b) Bit (c) KB (d) MB
  13. MS Word files are saved with which extension?
    (a) .xlsx (b) .pptx (c) .docx (d) .txt
  14. The shortcut Ctrl + Z is used to:
    (a) Save (b) Undo (c) Print (d) Close
  15. Which storage device is the fastest?
    (a) CD (b) HDD (c) USB drive (d) SSD
