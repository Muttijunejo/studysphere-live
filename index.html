Coding academy

Four starter lessons in simple English. Open a lesson, read it carefully, and type the example yourself — that is how programming is actually learned.

Lesson 1 — HTML: your first web pageHTML

HTML is the skeleton of every web page. Tags tell the browser what each part of the page is.

<!DOCTYPE html>
<html>
  <head><title>My first page</title></head>
  <body>
    <h1>Assalam-o-Alaikum</h1>
    <p>This is my first web page.</p>
  </body>
</html>

<h1> is a big heading, <p> is a paragraph. Almost every tag opens and closes — what goes between them is the content.

Lesson 2 — CSS: making pages clear and readableCSS

CSS controls how a page looks — colours, sizes, spacing and layout.

h1 { color: #166649; }
p { font-size: 18px; line-height: 1.6; }

Each rule names an element, then lists its styles inside curly brackets.

Lesson 3 — C++: variables and outputC++

C++ is the language taught in most Pakistani universities. A variable is a named box that stores a value.

#include <iostream>
using namespace std;
int main() {
    int marks = 85;
    cout << "My marks are " << marks;
    return 0;
}

int stores whole numbers, cout prints to the screen.

Lesson 4 — Python: a friendly startPython

Python reads almost like English, which makes it a good first language for data science and AI.

name = "MR Academy"
marks = [80, 75, 90, 88]
average = sum(marks) / len(marks)
print(name, "your average is", average)

No semicolons, no curly brackets — just clean, readable code.

Lesson 5 — C++: variables and data typesC++

A variable is a named box in memory where your program stores a value. Before you use a variable in C++, you must declare it with a data type. The type tells the computer what kind of value the box will hold, and how much memory it needs.

The common types are simple: int for whole numbers, double for decimal numbers, char for one character, string for text, and bool for true or false. Choose the right type for your data. For example, age is an int, price is a double, and a student name is a string.

#include <iostream>
#include <string>
using namespace std;

int main() {
    int age = 22;
    double marks = 69.5;
    string name = "Ali";
    bool passed = true;

    cout << name << " is " << age << " years old." << endl;
    cout << "Marks: " << marks << endl;
    return 0;
}

Remember two good habits: give variables clear names like totalMarks, and give them a starting value when you create them. This makes your code easy to read and avoids strange mistakes.

Lesson 6 — C++: loops made easyC++

A loop repeats a block of code many times, so you do not have to write the same line again and again. If you want to print numbers from 1 to 100, a loop can do it in three or four lines.

The for loop is best when you know how many times to repeat. It has three parts: a starting value, a condition, and a change after each round. The while loop is best when you do not know the count in advance — it keeps running while its condition stays true. Be careful: if the condition never becomes false, the loop never stops.

#include <iostream>
using namespace std;

int main() {
    // for loop: print 1 to 5
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }
    cout << endl;

    // while loop: count down from 3
    int n = 3;
    while (n > 0) {
        cout << n << " ";
        n--;
    }
    return 0;
}

Practice idea: write a loop that prints the table of 7, from 7 × 1 to 7 × 10. Small practice like this builds strong basics.

Lesson 7 — Python: lists and dictionariesPython

A list in Python stores many values in one variable, in order. You write it with square brackets, and you can add, remove, or change items. Lists are perfect for things like student names, marks, or daily temperatures. You reach one item by its index, and remember: the first item is at index 0.

A dictionary stores data as key and value pairs, like a real dictionary where each word has a meaning. Instead of a number index, you use a name — the key — to find the value. Dictionaries are ideal for one student's record, where "name", "age", and "city" are keys.

# A list of marks
marks = [78, 85, 90, 66]
marks.append(72)          # add one more mark
print(marks[0])           # first mark: 78
print(len(marks))         # total marks: 5

# A dictionary for one student
student = {
    "name": "Sara",
    "age": 21,
    "city": "Larkana"
}
print(student["name"])    # Sara
student["course"] = "Python"   # add a new key
print(student)

Simple rule to remember: use a list when order matters and items are similar; use a dictionary when each value needs a clear name.

Lesson 8 — Data science and AI: the beginner roadmapData Science

Data science means learning useful facts from data, and AI means teaching computers to learn patterns from that data. This field looks big, but beginners can start step by step. You do not need to be a genius — you need a clear order and daily practice.

Step 1: Maths basics. Learn percentages, averages, basic statistics, and simple probability. Step 2: Python. Python is the main language of this field, so learn it well, including lists and dictionaries. Step 3: Data handling. Learn to clean and explore data with tools like spreadsheets first, then Python libraries such as pandas. Step 4: The machine learning idea. Understand it simply: we give the computer many examples, it finds patterns, and then it can make predictions on new data.

Step 5: Build small projects and a portfolio. Start with simple projects, for example analysing student marks, predicting house prices from sample data, or making charts from cricket scores. Save your work on GitHub. Two or three honest, finished projects teach you more than ten unfinished courses — and they help a lot for scholarships and jobs.
